# 叮叮电台 · 使用教程

本文按「安装 → 添加电台 → 播放 → 后台收听 → 进阶设置」的顺序，介绍叮叮电台的完整用法。

## 1. 安装

1. 打开 [Releases](https://github.com/haijiang2023/tingting-radio/releases/latest)，下载最新版 APK。
2. 在 Android 系统设置中允许当前浏览器（或文件管理器）「安装未知应用」。
3. 点击 APK 完成安装。若系统提示风险，请先核对下载页给出的 SHA-256。
4. 本安装包为 **arm64-v8a** 构建，适用于绝大多数 Android 5.0 及以上手机；32 位老设备无法安装。

> 升级新版本时直接覆盖安装即可，电台与收藏数据会保留。

## 2. 首次启动

打开 App 进入「我的电台」页。首次启动只有 4 个 AsiaFM 示例台，用于验证播放是否正常。

页面结构：

- 顶部状态条：左侧为页面标识（如 `RADIO`），右侧为状态标签。
- 标题行：标题与台数计数。
- 主体：分类行在上、未分类电台行在下。
- 底部提示条：当前页的关键操作提示。

## 3. 添加电台

点击首页右上角 `+`，会看到四个入口：

| 入口 | 用法 |
|---|---|
| 添加电台 | 手动填写名称与流地址，并选择分类 |
| 从剪贴板导入 | 先把台源文本复制到剪贴板，再一次性解析导入 |
| 从在线库导入 | 搜索公共在线电台目录，选中后加入本机 |
| 新建分类 | 先建一个分类，再把电台放进去 |

### 手动添加

1. 填写电台名称，例如「亚洲粤语台」。
2. 填写流地址，需为可公开访问的 `http://` 或 `https://` 链接。
3. 选择分类（可留空；也可在弹窗里直接新建分类）。
4. 保存后回到首页，点击即可播放。

格式不需要手动选择：以 `.mp3` 结尾的按 MP3 裸流处理，以 `.m3u8` 结尾的按 HLS 处理。

### 从剪贴板导入

1. 在任意 App 中复制台源文本（每行一个地址，或包含「名称 + 地址」的列表）。
2. 打开叮叮电台，点击 `+` →「从剪贴板导入」。
3. 核对解析结果后确认导入。

### 从在线库导入

1. 点击 `+` →「从在线库导入」。
2. 输入关键词搜索（如城市名、电台名）。
3. 选择需要的电台加入本机电台库。

## 4. 管理电台与分类

- **编辑**：长按电台或分类，弹出菜单后选择「编辑」。
- **移动**：长按电台，选择「移动」，把它放到其他分类或移回未分类。
- **删除**：长按后选择「删除」；删除分类后，组内电台会自动回落到未分类。
- 分类数量可以为 0，首页会自动变成「未分类电台」的平铺列表。

## 5. 播放

- 点击任意电台立即开始播放。
- 播放页显示台名、格式标签、实时墨条频谱、直播计时、传输控制与音量条。
- 传输控制：
  - **播放 / 暂停**：暂停后再次点击继续。
  - **上一台 / 下一台**：在当前列表内循环切换。
  - **停止**：结束播放并释放媒体资源。
- 直播流没有总时长，进度条显示已播时长与 `LIVE` 标识。

## 6. 收藏与续听

- 播放页点击星标即可收藏 / 取消收藏。
- 底部「收藏」Tab 直达已收藏电台。
- 冷启动后会恢复到上次收听的电台，最近收听会置顶显示。

## 7. 音量

- 播放页音量条直接读写 **Android 系统媒体音量**：拖动音量条，系统音量同步变化，且不会弹出系统原生音量面板。
- 按手机实体音量键，App 内音量条会同步回填。
- 音量条旁 `+ / -` 按系统 1 档步进。
- 设备音量被系统固定或读取失败时，会自动降级为 App 内增益。

## 8. 后台与锁屏播放

- 播放由前台媒体服务承载，配合唤醒锁，息屏、切后台都不会断流。
- 通知栏与锁屏显示当前电台，并提供播放 / 暂停 / 上一台 / 下一台 / 停止。
- 拔出耳机自动暂停，重新播放需手动触发。
- 被来电或其他应用抢占音频时会自动让出，挂断后可手动恢复。
- 若系统省电策略较强，建议在系统设置中允许本应用后台运行，避免被清理。

## 9. 睡眠定时

在播放页打开睡眠定时，可选择 15 / 30 / 60 分钟，倒计时结束后自动暂停播放。

## 10. 播放失败与自动切台

- 电台源失效、网络异常时会显示错误提示。
- 开启「失败自动切台」后，会在连续失败时自动尝试下一台，避免卡在无声状态。
- 第三方转流地址存在失效或地域限制的可能，建议多备几个同类台源。

## 11. 数据与隐私

- 电台、分类、收藏、最近播放、音量等数据只保存在本机应用数据中。
- 不需要登录账号，不上传你的电台列表。
- 卸载应用会一并清除上述数据。

## 12. 卸载与更新

- **更新**：下载新 APK 覆盖安装，本地数据保留。
- **卸载**：长按应用图标选择卸载，或在系统设置中卸载；卸载后本地数据清除。
